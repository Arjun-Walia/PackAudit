# Clause checklist (Phase 1 exit)

A human must be able to apply this to a pack without the model.

- Manufacturer / packer / importer name & address
- Country of origin (imports)
- Generic name
- Net quantity in standard unit
- MRP allowed wording, inclusive of all taxes, INR
- Unit sale price
- Month & year of manufacture / packing / import
- Consumer care phone + email
- PDP, Table I height, letter width ≥ 1/3 height
- Quantity isolation, contrast
- Hindi (Devanagari) or English
- Rule 6(10) listing declarations
- Rule 6(10A) searchable/sortable COO filter (from 2026-07-01)
- Rule 18(2A) dual MRP (flagged)

See `rules/lmpc/v2026_07/pack.json`.
